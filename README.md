# cameia-gateway

API Gateway de CAMEIA. Centraliza el punto de entrada y el enrutamiento hacia los microservicios del MVP.

## Estado

Configuración inicial del Sprint 1. La estructura y las dependencias se implementarán mediante [CM-104](https://f0rktech.atlassian.net/browse/CM-104).

## Alcance

- Recibir solicitudes dirigidas a las APIs del MVP.
- Enrutar solicitudes hacia el microservicio correspondiente.
- Incorporar controles transversales cuando sean definidos y aprobados.

### Fuera de alcance

- Implementar reglas de negocio de los microservicios.
- Almacenar secretos o credenciales.
- Declarar autenticación, autorización o despliegue como implementados sin evidencia.
